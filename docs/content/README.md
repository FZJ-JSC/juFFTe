# juFFTe Documentation

This directory contains the documentation for the juFFTe library.

## Building Documentation

### Prerequisites

Install FORD (Fortran Documentation Generator):

```bash
pip install ford
```

### Build

From the project root:

```bash
# Using FORD directly
ford ford.md

# Or using the docs Makefile
make -C docs docs

# Or from src directory
make -C src docs
```

### View

Open the generated documentation:

```bash
open docs/api/ford/index.html
```

## Documentation Structure

- `ford.md` - FORD configuration file
- `index.md` - Main documentation page
- `api/` - API reference (auto-generated by FORD)
- `tutorials/` - Step-by-step tutorials
- `examples/` - Code examples

## Auto-generated API Reference

The API reference is automatically generated from source code comments using FORD. To update the API docs:

```bash
make -C docs docs
```

## Continuous Integration

Documentation is automatically built and deployed on pushes to `main` via GitHub Actions. See `.github/workflows/docs.yml`.

## Contributing

When adding new functions or modules, please add FORD-compatible comments:

```fortran
!> @brief Description of the function
!> 
!> Detailed description goes here.
!>
!> @param input Input parameter
!> @param output Output parameter
!> @return Status code
function my_function(input) result(output)
```
